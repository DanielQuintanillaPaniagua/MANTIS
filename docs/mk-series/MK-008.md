## 1. Objetivo

Construir una interfaz web (Dashboard) que permita visualizar los resultados del motor de MANTIS, gestionar objetivos y ejecutar escaneos sin usar la terminal.

## 2. Tecnologías

- **Backend:** Django 5.x (SQLite).
- **Frontend:** HTML5, CSS3 (Personalizado), Bootstrap 5.3 (vía CDN), Bootstrap Icons.
- **Integración:** El dashboard importa `src/mantis/` como librería a través de `services.py`.

## 3. Módulos implementados

1. **Dashboard:** Resumen de scans, hallazgos por tipo/severidad, estado del sistema y campana de notificaciones funcional.
2. **Scans:** Historial de análisis, formulario para iniciar escaneos (ejecuta BOLA, BFLA y State Skip síncronamente).
3. **Findings:** Listado global de vulnerabilidades con filtros por tipo/severidad y búsqueda de texto.
4. **Evidence:** Detalle de cada hallazgo (MK-007) con peticiones HTTP de evidencia y pasos de reproducción.
5. **Reports:** Listado de informes exportados (enlaces de descarga).
6. **Targets:** CRUD para gestionar APIs autorizadas para pruebas.

## 4. Identidad Visual

Se rediseñó la interfaz para parecerse a un "Centro de Operaciones" (inspirado en interfaces tácticas/cyberpunk).
- Colores: Negro profundo (`#050505`), Verde Neón (`#00ff41`).
- Tipografía: `Orbitron` (títulos) y `Share Tech Mono` (datos).
- Layout: Sidebar lateral fijo, topbar con búsqueda global y notificaciones.

## 5. Integración con el motor

- La lógica de `services.py` es la única que importa `mantis.analysis` y `mantis.spec`.
- No se ha duplicado lógica de detección. El dashboard actúa como una capa de presentación.

## 6. Instalación y uso

1. Entrar a la carpeta del dashboard: `cd dashboard`
2. Instalar dependencias: `pip install -r requirements.txt`
3. Aplicar migraciones: `python manage.py migrate`
4. Arrancar el servidor: `python manage.py runserver 127.0.0.1:8001`
5. Abrir en el navegador: `http://127.0.0.1:8001`
