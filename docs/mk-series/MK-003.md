## 4. Decisiones tomadas

### 4.1 — Política de destinos (H-01)

| Campo | Valor por defecto |
|---|---|
| `allowed_schemes` | `("http", "https")` |
| `allowed_hosts` | `("127.0.0.1", "localhost", "::1")` |
| `allowed_ports` | `(8000,)` |

**Falla cerrado:** cualquier URL que no esté en las listas se rechaza
antes de enviar la petición. Configurable desde `MantisConfig`.

### 4.2 — Redacción de evidencia (H-02)

**Headers redactados por defecto:**

- `authorization`
- `x-api-key`
- `cookie`
- `set-cookie`
- `proxy-authorization`

**Query params redactados por defecto:**

- `api_key`
- `token`
- `access_token`
- `key`
- `secret`
- `password`

**Case-insensitive.** Se aplica a headers de request, headers de
response y query params. El valor se reemplaza por `***REDACTED***`,
no se elimina el header (para preservar la estructura).

### 4.3 — Manejo de errores de log (H-03)

| Escenario | Comportamiento | Exit code |
|---|---|---|
| Log no se puede abrir | Petición **no** se ejecuta | 4 |
| Petición ejecutada, log falla al escribir | Se avisa, evidencia perdida | 5 |

### 4.4 — Exit codes finales

| Código | Significado |
|---|---|
| 0 | Éxito |
| 1 | Error de red (timeout, connection, DNS) |
| 2 | Error de argumentos (header malformado, timeout inválido) |
| 3 | Rate limit excedido |
| 4 | Target no permitido **o** log no se pudo abrir |
| 5 | Petición ejecutada, evidencia no guardada |

**Nota:** `4` se usa para dos causas distintas. Se acepta por simplicidad
en MK-003.1. Si se vuelve confuso, se separará en `6` en un hito futuro.
